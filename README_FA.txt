شاهین موتور - بسته اجرای خودکار پچ ثبت‌نام و CRM

فایل اصلی برای اجرا:
APPLY_PATCH_AND_RUN.bat

روش استفاده:
1) این zip را در کنار پوشه پروژه یا داخل همان سیستم اکسترکت کنید.
2) روی APPLY_PATCH_AND_RUN.bat دابل‌کلیک کنید.
3) اگر مسیر پروژه خودکار پیدا نشد، مسیر پوشه‌ای را بدهید که manage.py داخل آن است.
4) اسکریپت این کارها را انجام می‌دهد:
   - پچ را از داخل payload باز می‌کند
   - فایل‌های قبلی را بکاپ می‌گیرد
   - فایل‌های پچ را روی پروژه کپی می‌کند
   - pip install -r requirements.txt را اجرا می‌کند
   - migrate و check را اجرا می‌کند
   - پروژه را روی یکی از پورت‌های 8000/8001/8002/8010 بالا می‌آورد

پوشه‌های خروجی:
- logs : لاگ نصب و لاگ سرور
- backup_before_patch_* : بکاپ فایل‌های قبلی قبل از جایگزینی

نکته:
این بسته خطاهای رایج را خودکار پوشش می‌دهد، اما خطاهای سفارشی محیط، قطعی اینترنت برای pip، یا تنظیمات خاص سرویس پیامک/گوگل ممکن است هنوز نیاز به پچ بعدی داشته باشد.
